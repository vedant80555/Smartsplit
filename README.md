# SmartSplit

SmartSplit is a web-based smart expense splitter built using Flask and SQLite.

## Features

- Add people
- Add expenses
- Select expense participants
- Calculate expense shares
- Track payments
- View expense history
- View balances and settlements

## Technologies

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML/CSS
- GitHub Actions
