# SmartSplit

SmartSplit is a web-based smart expense splitter built using Flask and SQLite.

## Features

- Add people
- Add expenses
- Select expense participants
- Calculate expense shares
- Track payments
- View expense history
- View balances and settlements

## Technologies

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML/CSS
- GitHub Actions

## How to Run Locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using pip install -r requirements.txt.
4. Run the Flask application.
5. Open the application in a web browser.
